# Fidelity notes

How this game reads _Infinite Jest_'s "Interdependence Day" chapter (pp. 321–342 in
the Little, Brown first edition) and endnotes 121–130, and every place it has to
decide something the novel leaves open. Where the novel and this file disagree,
the novel wins and this file gets a new row.

Offer "Pemulis's shortcut" ((r+R)/2) as a labeled option, off by default, and "Old rules: Yahtzee dice" as another. | A6  | Map projection and which court holds which region.                                                                                                                                                      | Four courts with run-off side by side: 73.15 m east–west by 36.57 m north–south, a 2:1 equirectangular world map centered on Greenwich. ## Further readings made while building

| #   | Question                                                                    | Reading implemented                                                                                                                                                                                                                                                                                                                                                        | Since |
| --- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| A15 | The novel gives no GNP, budgets, histories, demographics or psych profiles. | Every figure in `src/engine/data/combatants.ts` is invented. They are tuned so the formula reproduces the outcomes the chapter does give: AMNAT and SOVWAR near 400 Mt each, and SOUTHAF with sixteen warheads.                                                                                                                                                            | M1    |
| A16 | How "normalize to about 400 Mt" turns ratios into balls.                    | Megatons per unit of ratio are set so the mean of AMNAT's and SOVWAR's figures is exactly 400 Mt (if neither plays, the largest figure gets 400 Mt). Each Combatant gets the nearest whole number of 5 Mt warheads, at least one. If that would use more than the 400 balls, every formula allocation is scaled down to fit. Balls nobody is allocated stay in the supply. | M1    |
| A17 | How the old red Yahtzee dice allocated megatonnage.                         | The novel only says allocation used to be done with them. Here each Combatant rolls its own number of dice (AMNAT and SOVWAR five, REDCHI three, INDPAK two, the rest one), and the sum goes through the same scaling as a ratio. The dice are seeded, so a game replays.                                                                                                  | M1    |
| A18 | How the insurgent cell is armed.                                            | The formula describes states, not a cell. The cell gets a fixed six howitzer shells from the same ball supply, owns no target items, and has its howitzer emplaced where the World Situation says (by default Windsor, Ontario, within range of Detroit).                                                                                                                  | M1    |
