# Fidelity notes

How this game reads _Infinite Jest_'s "Interdependence Day" chapter (pp. 321–342 in
the Little, Brown first edition) and endnotes 121–130, and every place it has to
decide something the novel leaves open. Where the novel and this file disagree,
the novel wins and this file gets a new row.
